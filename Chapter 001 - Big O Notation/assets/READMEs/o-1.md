# O(1) - Constant Time

**_Constant time complexity means that the running time of an algorithm remains constant with respect to the growth of the size of the input._**

No matter how big the input is, the opeartion takes the **same** amount of time to get executed.

```python
def get_first_element(array):
    return array[0]
```

This function always performs 1 step, whether the `array` has 5 elements or 5 million elements.

Array indexing is **O(1)** because arrays store elements at predictable memory addresses. Computer can just jump straight to that address and fetch it, no searching needed.

Some other **O(1)** examples:

- Pushing/Popping from the end of an array
- Hashmap lookup (`obj[key]`)
- Checking if a number is even or not
